Already use another AI app? **External access** lets it read the data connected to a company in Lemonado.

You need to be a workspace owner or admin to set this up.

## Connect an app

1. Open the company and click the gear beside its name.
2. Choose **External access** and turn the connection on.
3. Select your AI app and follow its connection guide.
4. Ask a question in that app to check the connection.

Lemonado calls this connection an **MCP**. You do not need to write code to follow the in-app setup.

For ChatGPT and Claude, directory connections are available once Lemonado is published in the app's directory. Follow the selected app's guide in Lemonado.

<Warning>
  Only connect apps you trust with the company's data. In an agency workspace, check that you have opened the right client first.
</Warning>

To stop access, return to **External access** and turn the connection off.

## What the connection uses

The connection gives your AI app tools to work with the data you allow it to access. Some tools return data for your AI app to interpret; the dedicated ChatGPT and Claude analysis tools also run analysis inside Lemonado.

Lemonado's saved memory and instructions are not loaded through these MCP tools. Give your external AI app any business context or reporting rules it needs separately.

See the [MCP reference](/mcp-reference) for the server address, available tools, permissions, and examples.
