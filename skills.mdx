Skills are reusable instructions for jobs such as a campaign review. They save you from explaining the same process every time.

<Frame caption="Browse skills by the kind of work you want to complete.">
  <img src="/images/screenshots/skills.png" alt="Skills catalogue with Browse, Installed, and My skills tabs and marketing categories" />
</Frame>

## Use a skill

1. Open **Skills → Browse** and choose a skill.
2. Review **What you get** and the connections it needs.
3. Click **Install**, then **Use this skill**. An owner or admin can install it if you cannot.
4. Add the company, dates, and other details in chat.

You can also type `/` in chat to choose an installed skill.

<Frame caption="Read the example and check the connections before you install a skill.">
  <img src="/images/screenshots/skill-details.png" alt="Ad fatigue skill showing an example result, required connections, and the Install button" />
</Frame>

## Run it regularly

Choose **Schedule** on the skill page to set up a [routine](/routines). Review the details in chat before confirming.

## Make it your own

Owners and admins can use **Create skill** to save a team's process. Include the steps, the expected result, and what to check before finishing. Find custom skills under **My skills**.

<Tip>
  A skill describes how to do a job. A routine decides when to do it.
</Tip>
