Skills are ready-made instructions for common marketing jobs. They help your team get a consistent result without rewriting the same request.

<Frame caption="Browse skills by the kind of work you want to complete.">

## Use a skill

1. Open **Skills** and choose a category.
2. Select a skill and review what it does.
3. Start it from the skill page, or type `/` in chat and choose it there.
4. Add the company, time period, or channel when Lemonado asks.

## Make it your own

Use **Create skill** when your team repeats the same process. Describe the steps, the expected result, and what Lemonado should check before it finishes.

<Tip>
  Agencies can reuse one strong skill across clients. The client’s own data and memory stay separate.
</Tip>
