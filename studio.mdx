Use Studio to make a report for a meeting, a dashboard to check regularly, or slides to share with a client.

  <img src="/images/screenshots/studio.png" alt="Studio with Dashboard, Report, and Slides creation options and saved work below" />

## Create something new

1. Open **Studio**.
2. Choose **Report**, **Dashboard**, or **Slides**.
3. Choose **Start blank** or a template.
4. Describe the audience and the decision the work should support.
5. Review the result and ask for changes in the attached chat.

<Frame caption="Use the chat beside your work to ask questions or make changes. This example uses sample data.">
  <img src="/images/screenshots/studio-editor.png" alt="Studio dashboard editor beside a chat explaining the sample campaign results" />
</Frame>

## Send a regular update

Open the finished work and choose **Schedule**. Set how often it runs, the time zone, and the dates each update should cover. Choose who to notify when it is ready.

<Frame caption="Choose when the update runs and which dates it covers before you create the schedule.">
  <img src="/images/screenshots/studio-schedule.png" alt="Schedule dialog with weekly frequency, Monday run time, time zone, and a seven-day data window" />
</Frame>

You can find scheduled reports again in [Routines](/routines).

<Tip>
  Before sharing, check the date range, sources, and conclusions. Ask Lemonado to explain anything that looks unusual.
</Tip>
