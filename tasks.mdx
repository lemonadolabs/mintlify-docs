Tasks are for work you want Lemonado to repeat or run on demand.

<Frame caption="Describe the recurring result you want, then let Lemonado build the steps.">
  <img src="/images/screenshots/tasks.jpg" alt="New task workspace with a weekly paid media summary request" />
</Frame>

## Create a task

1. Open **Tasks** and click **New**.
2. Describe what should happen and which source to use.
3. Choose when it should run.
4. Choose where the result should appear, such as Lemonado, email, or Slack.
5. Review the setup before you turn it on.

For example:

> Every Monday morning, summarize last week’s paid media performance and post the key changes to Slack.

## Keep tasks healthy

Open a task to review past runs, change its schedule, or pause it. Keep the request narrow so the result stays easy to review.

<Note>
  **Pulse** is always on. It looks for useful signals and shows them on Home.
</Note>
