Connectors let Lemonado work with tools such as your ad platforms, analytics, and spreadsheets. Start with the account you use most.

<Steps>
  <Step title="Open Connectors">
    Choose **Connectors** in the left menu.
  </Step>
  <Step title="Find your tool">
    Search by name or browse the featured connections.
  </Step>
  <Step title="Connect it">
    Select the tool and follow the sign-in steps. Choose the account you want Lemonado to use.
  </Step>
  <Step title="Check the connection">
    Open **Installed** to see the tools added to this company. Check that the right accounts are selected.
  </Step>
</Steps>

## Choose what Lemonado can do

Some connectors can make changes as well as read data. An owner or admin can set each action to **Off**, **Ask**, or **Approve**.

Choose **Ask** when you want to review an action before it runs. **Approve** lets that action run without asking each time.

<Tip>
  In an agency workspace, a shared connection still needs to be installed for the right client. Check the client name before adding an account.
</Tip>

You can also upload a CSV. If you cannot add a connection, ask your workspace owner or admin.
