## Frequently Asked Questions

What is an MCP and why does it matter?

MCP (Model Context Protocol) is the open standard that lets AI tools like ChatGPT, Claude, and Cursor securely connect to external data and tools. With Lemonado's MCP, your AI tools get access to your live, blended marketing data instead of guessing or pulling from one platform at a time.

It matters because the AI tool you already use becomes dramatically more useful the moment it can answer real questions about your campaigns, clients, and revenue.

Which AI tools can I connect via MCP?

ChatGPT, Claude, Cursor, n8n, and any other tool that supports MCP. Once Lemonado's MCP is connected, the AI can query your live marketing data the same way Lemonado's own chat does.

How do I set up an MCP connection?

One click inside Lemonado. Pick the workspace you want to expose, generate a connection, and paste it into ChatGPT, Claude, Cursor, or any MCP-compatible tool. Each connection is per-workspace, scoped, and read-only.

Is connecting Lemonado's MCP to ChatGPT or Claude secure?

Yes. Each MCP connection is scoped to a single workspace and read-only. Your AI tool never touches the underlying platform credentials, only the governed data inside Lemonado. You can revoke a connection at any time, and every query is logged.
